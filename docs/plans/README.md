# Plans

Live plans for this repo, one file each: `<model>-<YYYY-MM-DD>-<slug>.md`
(the `write-plan` skill). Each opens with a `Status:` line that leads with
its state: draft · in progress · blocked · finished. `.githooks/pre-commit`
checks new plans. Finished plans move to `project/archive/`.

Cross-repo plans for Project Wildshard live in
`Raynos/project-wildshard-meta` under `docs/multi-repo/`.
