# multi repo wildshard mmo concept.

All repos private. Install via git tags.

 - project-wildshard/shardfile

The raw shardfile spec, the raw shardfile validator, raw spec, raw validator. Depends on nothing. Validator can be CLI too.

 - project-wildshard/api-server

The API server for uploading user generated shards, used by people developing shards,
sharddev and engine server.

iEverything from the stupid vercel APIs can go into the api server.
Can be thin wrapper around R2. Validates upload.

Depends on the shardfile.

 - project-wildshard/engine

Which contains
  ./shared ( protocol, snapshot, movement, collisison, entity state, replication of entityt state etc etc )
  ./client ( the client side of the engine, the game )
  ./server ( the server side of the engine, the MMO server )
  ./cook ( shardfile -> runtime packs )

The shardfile is the raw upload, the engine only runs on packs it cooked itself.
The engine itself has lint rules to make sure ./client and ./server are completely seperate
The engine has build targets to output the client and server binaries/websites as seperate things.

Depends on shardfile

 - project-wildshard/sharddev

The local dev server, including model explore, set explore, world explore, arena etc.
The draft tool.
The cli for baking and building a shardfile output from a shardsource source code directory.

Depends on engine, shardfile.

 - project-wildshard/www.wildshard.io

The marketing website

 - project-wildshard/leftover

All the leftover junk i forgot about. ( admin console, native apps, infra )
