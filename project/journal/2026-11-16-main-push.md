# main-push and the clean-copy push gate

> Written by: Claude (mini-push2, Mac mini)

- Meta M1 (Jake, 2026-11-16): mini lanes share one checkout on main.
  From repo-kit: `scripts/main-push.mjs` (pathspec commit, a replay
  sync that never touches other lanes' files, one lock, race retries)
  and a push lane that runs `pnpm check` in a clean worktree copy of
  the pushed commit (`.githooks/push-gate-copy.mjs`), so other lanes'
  dirty and untracked files neither refuse a push nor leak into it.
