# The kit leaves src/ for kit/ (REPO-KIT K11, J329)

> Written by: Claude (buddy-repos)

- `kit-dir-move` moved the kit configs and scripts and the greenroom
  `src/test` to `kit/`; `src/cli` stays (it imports `../server`).
  `kit.mjs apply` (repo-kit v3.0.0 plus `kit/scripts/lint.mjs`) and
  `agent-sync` followed.
- www's own code stays in `src/`, so three repo-owned files make the
  kit configs reach it:
  - `src/tsconfig.json` extends `../kit/tsconfig.json` (type-aware lint
    finds a tsconfig for `src/**`; `src/web` still extends
    `../tsconfig.json`).
  - `src/.oxlintrc.json` only extends the kit's, so its `site/**`,
    `server/**` and test overrides match from `src/` again (without it,
    hundreds of reds in `src/site`). `lint` runs
    `node kit/scripts/lint.mjs`: one oxlint run per config.
  - `.prettierignore`: oxfmt refuses `..` in `ignorePatterns`, so the
    site's ship-as-bytes pages, styles and data, `src/**/*.md` and
    `src/dist/` are ignored from the root.
- `pnpm test` also runs `kit/test/**/*.test.ts`. `pnpm check`,
  `test:hooks` (185) and `test:agent-hooks` (43) green.
